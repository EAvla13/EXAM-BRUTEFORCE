# EXAM-BRUTEFORCE

Para poder correr el programa se necesita tener una terminal WSL

primero se debe crear el entorno virtual, por lo cual tenemos que seguir los siguienets pasos:
  - python3 -m venv venv
  - source venv/bin/activate
  - uvicorn main:app --port 5000 --reload
Una vez corrida la API ingresamos todos los archivos en una carpeta debajo de la carpeta "__pycache__" y "venv"

Si se desea correr la API en internet usamos este link http://127.0.0.1:5000/docs
con este link podremos utlizar todo el programa
